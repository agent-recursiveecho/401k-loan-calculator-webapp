# User guide
1. Confirm eligible gross earnings and take-home figures from pay statements.
2. Enter loan proceeds and financed fee separately; enter actual disbursement date when known.
3. Set next payday, first loan deduction date, and the payroll processing delay.
4. Adjust contribution rates and employer match to compare paycheck effects.
5. Enter all expenses and an opening account balance to avoid misleading cash-flow projections.
6. Examine warnings, projected low balance, and the timeline. Export CSV when needed.
